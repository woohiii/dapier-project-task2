# 4. 실물 평가

**결과 보고서 (그래프):** https://claude.ai/artifact/HeEQYUe4Gk3qFpaMjXTgHa · 같은 파일: [`report/towel_half42_eval_1023.html`](../report/towel_half42_eval_1023.html) (내려받아 브라우저로 열기)

## 추론 프로그램과 관절 제한

추론은 `run_act_towel_bimanual_lim9.py`(so101-bimanual-teleop)를 감싼 [`scripts/eval/run_act_towel_bimanual_wide.py`](../scripts/eval/run_act_towel_bimanual_wide.py)로 합니다. `--limit-deg L` 하나로 세 가지를 함께 바꿉니다.

| 항목 | lim9 기본 | wide |
|---|---|---|
| 정책 목표 제한 (현재 관절 ± 몇 도까지) | 9° | L |
| 명령 분할 (waypoint) | 5° | L (스텝당 한 번에 보냄) |
| 팔로워 모터 가드 | 10° | L + 5° |

배경: 10/22에 lim9 스크립트에서 waypoint 사이의 중복 대기를 없애자, 같은 `--control-hz 30`에서도 실제 루프가 약 15Hz에서 약 22Hz로 빨라졌습니다. 그러면서 9° 제한에 자주 걸려 수건을 끄는 힘이 모자랐습니다. 제한을 12°/15°로 넓히자 실제 루프가 약 29.6Hz가 됐습니다. 이때 관절 속도 p95는 약 40°/s로 사람 시연(p95 37°/s)과 비슷하고, 모터 사양(약 270°/s) 안에 있습니다.

## 평가 절차

[`scripts/eval/run_act_eval_half42.sh`](../scripts/eval/run_act_eval_half42.sh) (`LIMIT_DEG=12` 또는 15)

1. 수건을 L자 테이프에 맞춰 놓고 팔 주변을 비운 뒤 Enter를 누릅니다.
2. 정책을 30Hz로 최대 150초 실행합니다. 작업자가 완료나 실패를 보고 Enter로 멈춥니다.
3. 결과 코드를 입력합니다. `full_success`(대문접기까지 성공), `right_gate`(오른쪽 대문접기까지), `half_only`(반접기만), `grasp_fold_fail`(잡았지만 못 접음), `no_grasp`(못 잡음)입니다. 메모를 남기면 `results.csv`에 바로 저장됩니다.
4. 한 번 실행에 5회를 하고 멈춥니다. 다시 실행하면 같은 폴더에 이어서 6~10회를 합니다.
5. 시행마다 `trace/`에 카메라 4개 영상(avi)과 `actions.jsonl`(스텝별 현재 관절·목표 관절·시각)이 남습니다.

시작 전에 Astra 워치독을 켜 두어야 합니다.

|---|---|---|---|---|---|

시행별 결과와 메모: [`results/`](../results) 폴더의 `act_*.csv` (메모는 뜻을 유지하고 기술 메모 형태로 정리). 시행별 계산 지표: [`results/trial_metrics.json`](../results/trial_metrics.json) ([`scripts/eval/trial_metrics.py`](../scripts/eval/trial_metrics.py)로 계산)

### 시간 (성공한 시행 평균, B안 lim12)

| 단계 | 시각 |
|---|---|
| 왼손 집기 | 약 5.4 s |
| 오른손 집기 | 약 10.1 s |
| 반접기 완료 (오른손 놓음) | 약 20.0 s |
| 작업자 정지 | 약 49.4 s (사람 반응 시간 포함) |

집기는 그리퍼가 20° 넘게 열린 뒤 처음 10° 아래로 닫힌 시각이고, 놓음은 그 뒤 다시 20° 넘게 열린 시각입니다.

### 해석

- **lim12를 기본으로 정했습니다.** lim15와 루프 속도·관절 속도가 같고 성공 수 차이는 1회뿐이라, 모터가 걸렸을 때 덜 세게 미는 쪽을 택했습니다.
- B안은 반접기 품질 불만이 거의 없어졌습니다. 70개 모델은 10회 중 7회 메모에 반접기가 미흡하거나 불완전하다는 내용이 있었습니다. 다만 70개 모델은 5회씩만 시험했기 때문에 성공률을 직접 비교하기에는 횟수가 부족합니다.
- 가까운 거리 20회 중 대문접기를 완성하지 못한 5회 가운데 3회가 **오른손 집기 실패**였습니다.

### 트롤리를 멀리 두었을 때 (1/10)

[`scripts/eval/right_grasp_pose.py`](../scripts/eval/right_grasp_pose.py)로 오른손 그리퍼가 닫히는 순간의 오른팔 관절을 비교했습니다.

| 조건 | 오른팔 pan / shoulder_lift / elbow_flex |
|---|---|
| 가까운 거리 (lim12, 10회) | 17~20° / 18~26° / 24~32° |
| 먼 거리 (실패 시행) | 16~18° / 18~24° / 28~34° |

**정책은 수건이 멀어져도 학습 때 외운 자세까지만 뻗고 그리퍼를 닫습니다.** 팔이 닿지 않는 것이 아니라, 카메라를 보고 뻗는 거리를 늘리지 않는 것입니다. 그래서 거리는 이동 장치 쪽에서 맞추기로 했습니다([06_next_steps.md](06_next_steps.md)).
